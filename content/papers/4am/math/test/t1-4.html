التمرين الثاني (12 نقطة)

$ABC$ مثلث قائم في $A$ حيث: $AB = 6\,\text{cm}$ و $AC = 8\,\text{cm}$.

  1. احسب الطول $BC$.
  2. احسب $\cos\widehat{ABC}$ و $\sin\widehat{ABC}$ و $\tan\widehat{ABC}$.
  3. تحقق أن $\cos^2\widehat{ABC} + \sin^2\widehat{ABC} = 1$.
  4. استنتج قيس الزاوية $\widehat{ABC}$ بالتدوير إلى الدرجة، ثم قيس $\widehat{ACB}$.

التمرين الأول

$A = (\sqrt{5})^2 - 1^2 = 5 - 1 = 4$

$B = \sqrt{\dfrac{48}{3}} = \sqrt{16} = 4$

$C = \sqrt{36} = 6$

$D = \dfrac{10\sqrt{5}}{5} = 2\sqrt{5}$

التمرين الثاني

1) حسب فيثاغورس: $BC^2 = 6^2 + 8^2 = 100$ ← $BC = 10\,\text{cm}$

2) $\cos\widehat{B} = \dfrac{AB}{BC} = 0{,}6$ ؛ $\sin\widehat{B} = \dfrac{AC}{BC} = 0{,}8$ ؛ $\tan\widehat{B} = \dfrac{AC}{AB} = \dfrac{4}{3}$

3) $0{,}6^2 + 0{,}8^2 = 0{,}36 + 0{,}64 = 1$

4) $\widehat{ABC} \approx 53°$

$\widehat{ACB} = 90° - 53° = 37°$
