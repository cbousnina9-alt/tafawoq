التمرين الأول (05 نقاط)

  1. حلّ في ℝ: |x − 3| = 5 ثم |x − 3| ≤ 5 واكتب الحل على شكل مجال.
  2. عيّن: [−2 ; 4] ∩ ]1 ; 7] و [−2 ; 4] ∪ ]1 ; 7].
  3. علمًا أن 1,41 < √2 < 1,42، أعط حصرًا للعدد 3 − 2√2.

التمرين الثاني (07 نقاط)

f(x) = x² − 4x + 1 معرّفة على ℝ.

  1. اكتب f(x) على الشكل النموذجي.
  2. استنتج اتجاه تغيّر f والقيمة الحدّية الصغرى.
  3. حلّ المعادلة f(x) = 1.
  4. قارن f(√3) و f(√5) دون حساب.

التمرين الثالث (08 نقاط)

في معلم متعامد ومتجانس، A(1 ; 2) ، B(5 ; 4) ، C(4 ; 6).

  1. احسب مركّبتي الشعاعين AB و AC.
  2. عيّن إحداثيتي D حتى يكون ABDC متوازي أضلاع (AB = CD).
  3. احسب الطول AB.
  4. عيّن إحداثيتي I منتصف [BC].

التمرين الأول

1) x − 3 = 5 أو x − 3 = −5 ⇒ x = 8 أو x = −2 ؛ |x − 3| ≤ 5 ⇔ −2 ≤ x ≤ 8 ⇒ x ∈ [−2 ; 8].

2) التقاطع: ]1 ; 4] ؛ الاتحاد: [−2 ; 7].

3) 2,82 < 2√2 < 2,84 ⇒ −2,84 < −2√2 < −2,82 ⇒ 0,16 < 3 − 2√2 < 0,18.

التمرين الثاني

1) f(x) = (x − 2)² − 3.

2) f متناقصة على ]−∞ ; 2] ومتزايدة على [2 ; +∞[، والقيمة الحدية الصغرى −3 عند x = 2.

3) x² − 4x = 0 ⇒ x(x − 4) = 0 ⇒ x = 0 أو x = 4.

4) حسب الشكل النموذجي، f(x) يكبر كلما ابتعد x عن 2: بُعد √3 عن 2 هو 2 − √3 ≈ 0,27، وبُعد √5 هو √5 − 2 ≈ 0,24، إذن f(√3) > f(√5).

التمرين الثالث

1) AB(4 ; 2) ؛ AC(3 ; 4).

2) نريد الشعاع CD = الشعاع AB: D = (4 + 4 ; 6 + 2) = (8 ; 8).

3) AB = √(16 + 4) = √20 = 2√5.

4) I((5 + 4)/2 ; (4 + 6)/2) = (4,5 ; 5).
