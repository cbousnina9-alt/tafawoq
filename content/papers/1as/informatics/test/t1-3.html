التمرين الثالث (08 نقاط)

على القرص D: أنشأ تلميذ المجلد Lycee، وبداخله المجلدان Maths وInfo. وضع في المجلد Info ملفًا اسمه tp1.docx.

  1. ارسم شجرة المجلدات.
  2. اكتب المسار الكامل للملف tp1.docx.
  3. ما الفرق بين «نسخ» ملف و«قص» ملف؟
  4. ماذا يحدث للملف عند حذفه؟ وكيف نسترجعه؟

التمرين الأول

1) نظام التشغيل: مجموعة برامج أساسية تدير مكونات الحاسوب وتسمح للمستخدم والبرامج بالتعامل معها.

الوظائف: تسيير الذاكرة والمعالج، تسيير الملفات، تسيير وحدات الإدخال والإخراج، توفير واجهة للمستخدم.

2) Windows، Linux (أو macOS) ؛ للهاتف: Android (أو iOS).

التمرين الثاني

.docx → b ; .mp3 → c ; .jpg → a ; .xlsx → e ; .mp4 → d ; .pdf → f

التمرين الثالث

1) D: → Lycee → { Maths , Info → tp1.docx }

2) D:\Lycee\Info\tp1.docx

3) النسخ ينشئ نسخة جديدة مع بقاء الأصل في مكانه، أما القص فينقل الملف من مكانه إلى مكان آخر.

4) ينتقل إلى سلة المهملات (Corbeille)، ونسترجعه بفتح السلة ثم اختيار «استعادة» (Restaurer).
