التمرين الأول (6 نقاط)

$(u_n)$ معرفة بـ: $u_0 = 1$ و $u_{n+1} = \dfrac{u_n}{1 + u_n}$ (نقبل أن $u_n > 0$ من أجل كل $n$).

  1. احسب $u_1$ و $u_2$.
  2. نضع $v_n = \dfrac{1}{u_n}$. بيّن أن $(v_n)$ متتالية حسابية يُطلب تعيين أساسها وحدها الأول.
  3. اكتب $v_n$ ثم $u_n$ بدلالة $n$، واحسب $\lim\limits_{n \to +\infty} u_n$.
  4. احسب $S_n = v_0 + v_1 + \cdots + v_n$.

التمرين الثاني (8 نقاط)

$f(x) = x^3 - 3x^2 + 4$ معرفة على $\mathbb{R}$.

  1. احسب نهايتي $f$ عند $-\infty$ و $+\infty$.
  2. احسب $f'(x)$ وادرس إشارتها، ثم شكّل جدول تغيرات $f$.
  3. تحقق أن $f(x) = (x + 1)(x - 2)^2$ ثم حل المعادلة $f(x) = 0$.
  4. اكتب معادلة المماس للمنحنى عند النقطة ذات الفاصلة $1$.

التمرين الثالث (6 نقاط)

$g(x) = \dfrac{x^2 + x + 1}{x}$ معرفة على $]0\,;+\infty[$.

  1. بيّن أن $g(x) = x + 1 + \dfrac{1}{x}$، واستنتج مستقيمًا مقاربًا مائلًا.
  2. احسب $g'(x)$ وادرس اتجاه تغير $g$.
  3. استنتج أن $g(x) \geq 3$ من أجل كل $x > 0$.

حل التمرين الأول

  1. $u_1 = \dfrac{1}{2}$ ، $u_2 = \dfrac{1/2}{3/2} = \dfrac{1}{3}$
  2. $v_{n+1} = \dfrac{1 + u_n}{u_n} = \dfrac{1}{u_n} + 1 = v_n + 1$: حسابية أساسها $1$ وحدها الأول $v_0 = 1$.
  3. $v_n = n + 1$ ، $u_n = \dfrac{1}{n + 1}$ ، $\lim\limits_{n \to +\infty} u_n = 0$.
  4. $S_n = \dfrac{(n + 1)(v_0 + v_n)}{2} = \dfrac{(n + 1)(n + 2)}{2}$

حل التمرين الثاني

  1. $\lim\limits_{x \to -\infty} f(x) = \lim x^3 = -\infty$ ؛ $\lim\limits_{x \to +\infty} f(x) = +\infty$.
  2. $f'(x) = 3x^2 - 6x = 3x(x - 2)$: موجبة على $]-\infty\,;0[$ و $]2\,;+\infty[$، سالبة على $]0\,;2[$. $f$ متزايدة ثم متناقصة ثم متزايدة، مع $f(0) = 4$ (قيمة حدية عظمى محلية) و $f(2) = 0$ (صغرى محلية).
  3. $(x + 1)(x^2 - 4x + 4) = x^3 - 4x^2 + 4x + x^2 - 4x + 4 = x^3 - 3x^2 + 4$ ✓. الحلول: $x = -1$ و $x = 2$ (مضاعف).
  4. $f(1) = 2$ ، $f'(1) = -3$:   $y = -3(x - 1) + 2$ أي $y = -3x + 5$.

حل التمرين الثالث

  1. $\dfrac{x^2 + x + 1}{x} = x + 1 + \dfrac{1}{x}$ ؛ و $g(x) - (x + 1) = \dfrac{1}{x} \to 0$ عند $+\infty$: المستقيم $y = x + 1$ مقارب مائل.
  2. $g'(x) = 1 - \dfrac{1}{x^2} = \dfrac{(x - 1)(x + 1)}{x^2}$: سالبة على $]0\,;1[$ وموجبة على $]1\,;+\infty[$.
  3. القيمة الحدية الصغرى $g(1) = 3$، إذن $g(x) \geq 3$.
