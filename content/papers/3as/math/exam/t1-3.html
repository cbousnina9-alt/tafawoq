التمرين الثاني (13 نقطة)

$f(x) = \dfrac{x^2 + x + 1}{x + 1}$ على $\mathbb{R} \setminus \{-1\}$ ، و $(C_f)$ تمثيلها البياني.

  1. بيّن أن $f(x) = x + \dfrac{1}{x + 1}$.
  2. احسب النهايات عند أطراف مجموعة التعريف.
  3. بيّن أن $(C_f)$ يقبل مستقيمين مقاربين يُطلب تعيين معادلتيهما، وادرس وضعية $(C_f)$ بالنسبة للمائل.
  4. بيّن أن $f'(x) = \dfrac{x(x + 2)}{(x + 1)^2}$ ، وشكّل جدول التغيرات.
  5. بيّن أن النقطة $\Omega(-1\,;\,-1)$ مركز تناظر لـ $(C_f)$.
  6. اكتب معادلة المماس عند النقطة ذات الفاصلة $1$.

التمرين الأول

1) $u_1 = 2$ ؛ $u_2 = \dfrac{2}{3} + 2 = \dfrac{8}{3}$

2) $v_{n+1} = \dfrac{1}{3}u_n - 1 = \dfrac{1}{3}(u_n - 3) = \dfrac{1}{3}v_n$ ؛ أساسها $\dfrac{1}{3}$ وحدها الأول $v_0 = -3$.

3) $v_n = -3\left(\dfrac{1}{3}\right)^n$ ومنه $u_n = 3 - 3\left(\dfrac{1}{3}\right)^n$

$\lim u_n = 3$ لأن $\lim\left(\dfrac{1}{3}\right)^n = 0$.

4) $S_n = 3(n + 1) + \left(v_0 + \dots + v_n\right) = 3(n + 1) - 3 \times \dfrac{1 - \left(\frac{1}{3}\right)^{n+1}}{\frac{2}{3}} = 3(n + 1) - \dfrac{9}{2}\left[1 - \left(\dfrac{1}{3}\right)^{n+1}\right]$

التمرين الثاني

1) $x + \dfrac{1}{x + 1} = \dfrac{x^2 + x + 1}{x + 1}$

2) $\lim\limits_{x \to -\infty} f(x) = -\infty$ ؛ $\lim\limits_{x \to +\infty} f(x) = +\infty$

$\lim\limits_{x \to -1^-} f(x) = -\infty$ ؛ $\lim\limits_{x \to -1^+} f(x) = +\infty$

3) $x = -1$ مقارب عمودي.

$\lim\limits_{x \to \pm\infty}\left[f(x) - x\right] = \lim \dfrac{1}{x + 1} = 0$: $y = x$ مقارب مائل.

$f(x) - x = \dfrac{1}{x + 1}$: $(C_f)$ فوق المائل على $]-1\,;\,+\infty[$ وتحته على $]-\infty\,;\,-1[$.

4) $f'(x) = 1 - \dfrac{1}{(x + 1)^2} = \dfrac{(x + 1)^2 - 1}{(x + 1)^2} = \dfrac{x(x + 2)}{(x + 1)^2}$

$f$ متزايدة على $]-\infty\,;\,-2]$ و $[0\,;\,+\infty[$ ، متناقصة على $[-2\,;\,-1[$ و $]-1\,;\,0]$ ؛ قيمة حدية عظمى محلية $f(-2) = -3$ وصغرى محلية $f(0) = 1$.

5) من أجل $x \neq -1$: $-2 - x \neq -1$ و $f(-2 - x) + f(x) = -2 - x - \dfrac{1}{x + 1} + x + \dfrac{1}{x + 1} = -2 = 2 \times (-1)$ ، إذن $\Omega(-1\,;\,-1)$ مركز تناظر.

6) $f(1) = \dfrac{3}{2}$ ، $f'(1) = \dfrac{3}{4}$: $y = \dfrac{3}{4}(x - 1) + \dfrac{3}{2} = \dfrac{3}{4}x + \dfrac{3}{4}$
