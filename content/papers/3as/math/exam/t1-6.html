التمرين الأول (08 نقاط)

(uₙ) متتالية معرّفة بـ: u₀ = 2 و uₙ₊₁ = ½ uₙ + 3.

  1. احسب u₁ و u₂.
  2. نضع vₙ = uₙ − 6. بيّن أن (vₙ) هندسية يُطلب أساسها وحدّها الأول.
  3. اكتب vₙ ثم uₙ بدلالة n.
  4. احسب نهاية (uₙ).
  5. احسب المجموع Sₙ = v₀ + v₁ + … + vₙ ثم Tₙ = u₀ + u₁ + … + uₙ.

التمرين الثاني (12 نقطة)

f دالة معرّفة على ]−1 ; +∞[ بـ: f(x) = x − 1 + 4/(x + 1)، و (C) تمثيلها البياني.

  1. احسب نهايتي f عند −1 من اليمين وعند +∞، وفسّر النتيجة الأولى بيانيًا.
  2. بيّن أن f'(x) = (x − 1)(x + 3)/(x + 1)² ثم شكّل جدول تغيّرات f.
  3. بيّن أن المستقيم (Δ): y = x − 1 مقارب مائل لـ (C) عند +∞، وادرس الوضع النسبي.
  4. اكتب معادلة المماس (T) عند النقطة ذات الفاصلة 0.
  5. بيّن أن المعادلة f(x) = 4 تقبل حلّين في ]−1 ; +∞[.

التمرين الأول

1) u₁ = 1 + 3 = 4 ؛ u₂ = 2 + 3 = 5.

2) vₙ₊₁ = uₙ₊₁ − 6 = ½uₙ − 3 = ½(uₙ − 6) = ½vₙ: هندسية أساسها q = ½ وحدّها الأول v₀ = −4.

3) vₙ = −4(½)ⁿ ؛ uₙ = 6 − 4(½)ⁿ.

4) بما أن 0 < ½ < 1 فإن (½)ⁿ → 0، إذن lim uₙ = 6.

5) Sₙ = −4 × (1 − (½)ⁿ⁺¹)/(1 − ½) = −8(1 − (½)ⁿ⁺¹) ؛ Tₙ = Sₙ + 6(n + 1) = 6n + 6 − 8 + 8(½)ⁿ⁺¹ = 6n − 2 + 8(½)ⁿ⁺¹.

التمرين الثاني

1) عند −1⁺: x + 1 → 0⁺ ⇒ 4/(x+1) → +∞ ⇒ lim f = +∞: المستقيم x = −1 مقارب عمودي. عند +∞: lim f = +∞.

2) f'(x) = 1 − 4/(x + 1)² = ((x + 1)² − 4)/(x + 1)² = (x − 1)(x + 3)/(x + 1)². على المجال x + 3 > 0 فإشارة f' من إشارة x − 1: f متناقصة على ]−1 ; 1] ومتزايدة على [1 ; +∞[، والقيمة الحدية الصغرى f(1) = 2.

3) f(x) − (x − 1) = 4/(x + 1) → 0 عند +∞ ⇒ (Δ) مقارب مائل. وبما أن 4/(x + 1) > 0 على المجال، فإن (C) فوق (Δ).

4) f(0) = 3 ، f'(0) = −3 ⇒ (T): y = −3x + 3.

5) f مستمرة ومتناقصة تمامًا على ]−1 ; 1] من +∞ إلى 2، و 4 ∈ ]2 ; +∞[ ⇒ حل وحيد في ]−1 ; 1[ ؛ ومتزايدة تمامًا على [1 ; +∞[ من 2 إلى +∞ ⇒ حل وحيد في ]1 ; +∞[. إذن حلّان (حسب مبرهنة القيم المتوسطة).
