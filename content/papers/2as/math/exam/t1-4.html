التمرين الأول (06 نقاط)

f(x) = 2x² − 5x − 3

  1. احسب المميز Δ وحلّ المعادلة f(x) = 0.
  2. حلّل f(x) إلى جداء عاملين.
  3. ادرس إشارة f(x) ثم حلّ المتراجحة f(x) ≤ 0.

التمرين الثاني (06 نقاط)

g(x) = −x² + 4x + 5

  1. اكتب g(x) على الشكل النموذجي.
  2. استنتج اتجاه تغيّر g وقيمتها الحدّية.
  3. حلّ المعادلة g(x) = 5.

المسألة (08 نقاط)

يريد فلاح إحاطة قطعة أرض مستطيلة بسياج طوله 60 m على ثلاث جهات فقط، والجهة الرابعة جدار. نسمّي x عرض القطعة (الضلعان العموديان على الجدار).

  1. عبّر عن الطول بدلالة x، ثم عيّن مجال x.
  2. بيّن أن المساحة S(x) = −2x² + 60x.
  3. عيّن قيمة x التي تجعل المساحة أعظمية واحسبها.
  4. عيّن قيم x التي تكون من أجلها المساحة أكبر من أو تساوي 400 m².

التمرين الأول

1) Δ = 25 + 24 = 49 ؛ x₁ = (5 − 7)/4 = −1/2 ، x₂ = (5 + 7)/4 = 3.

2) f(x) = 2(x + 1/2)(x − 3) = (2x + 1)(x − 3).

3) a = 2 > 0: f(x) موجب خارج الجذرين وسالب بينهما ؛ حل المتراجحة: x ∈ [−1/2 ; 3].

التمرين الثاني

1) g(x) = −(x² − 4x) + 5 = −[(x − 2)² − 4] + 5 = −(x − 2)² + 9.

2) g متزايدة على ]−∞ ; 2] ومتناقصة على [2 ; +∞[، وتقبل قيمة حدّية عظمى 9 عند x = 2.

3) −x² + 4x = 0 ⇒ x(−x + 4) = 0 ⇒ x = 0 أو x = 4.

المسألة

1) الطول = 60 − 2x، مع 0 < x < 30.

2) S(x) = x(60 − 2x) = −2x² + 60x.

3) S(x) = −2(x − 15)² + 450: المساحة أعظمية عند x = 15 m، وتساوي 450 m² (الطول 30 m).

4) −2x² + 60x − 400 ≥ 0 ⇔ x² − 30x + 200 ≤ 0 ؛ Δ = 100، الجذران 10 و 20 ؛ إذن x ∈ [10 ; 20].
